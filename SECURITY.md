# Security

rove is a math and geometry library; it reads no files but those its own `octree` save and load functions are given.

To report a vulnerability (for example, a crash or out-of-bounds access when loading a saved octree), use GitHub's private vulnerability
reporting (the repository's Security tab, "Report a vulnerability") with a description and, if possible, a file or a program that reproduces it. Please do not open a public issue for it.
